# 1. RNN — Recurrent Neural Networks

## 📘 About This Repository

This repository focuses on understanding and implementing **Recurrent Neural Networks (RNNs)**, a class of neural networks designed to process sequential data. Unlike traditional feedforward networks, RNNs maintain information from previous time steps, helping them learn patterns and dependencies within sequences.

The notebooks and experiments explore how recurrent connections work, how sequential information is processed, and how RNN models can be trained to make predictions from ordered data.

### 🧠 Topics Covered
- Fundamentals and architecture of Recurrent Neural Networks
- Sequential data processing and hidden states
- Forward propagation through time
- Backpropagation Through Time (BPTT)
- Loss functions, optimizers, and model training
- Introduction to Long Short-Term Memory (LSTM) and Gated Recurrent Units (GRU)
- Model evaluation and prediction analysis

### 🚀 Applications
- Time-series forecasting
- Text and sequence processing
- Sentiment analysis
- Predictive analytics
- Sequential pattern recognition

**Goal:** Develop a strong understanding of recurrent architectures and learn how neural networks can extract meaningful patterns from sequential data.


# 2. ANN — Artificial Neural Networks

## 📘 About This Repository

This repository explores **Artificial Neural Networks (ANNs)**, one of the fundamental building blocks of deep learning. Inspired by the interconnected structure of biological neurons, ANNs learn relationships between input features and target outputs by adjusting their internal weights and biases during training.

The focus is on understanding how neural networks learn, how information flows through different layers, and how model parameters are optimized to improve predictive performance.

### 🧠 Topics Covered
- Neural network architecture: input, hidden, and output layers
- Neurons, weights, biases, and activation functions
- Forward propagation
- Loss functions and error calculation
- Backpropagation and gradient descent
- Optimizers such as SGD and Adam
- Binary and multiclass classification
- Regression using neural networks
- Training, validation, and testing
- Overfitting, underfitting, and regularization
- Model evaluation and performance analysis

### 🚀 Applications
- Classification and regression
- Customer behavior prediction
- Fraud detection
- Predictive maintenance
- Risk analysis and decision support

**Goal:** Build a strong foundation in neural networks by understanding the complete learning process, from data preparation and forward propagation to backpropagation and model evaluation.


# 3. PyTorch — Deep Learning with PyTorch

## 📘 About This Repository

This repository contains hands-on experiments and implementations using **PyTorch**, an open-source deep learning framework widely used for developing and training neural networks. It focuses on learning PyTorch's core building blocks and applying them to practical machine learning and deep learning problems.

The emphasis is on writing understandable, modular code while gaining experience with tensors, automatic differentiation, neural network architectures, and complete model-training workflows.

### 🧠 Topics Covered
- Creating and manipulating tensors
- Tensor operations, shapes, dimensions, and broadcasting
- Automatic differentiation with `autograd`
- Building models using `torch.nn`
- Defining custom neural networks with `nn.Module`
- Loss functions and optimization algorithms
- Training and evaluation loops
- Working with datasets and `DataLoader`
- Managing gradients and optimizer updates
- Saving and loading trained models
- Using GPUs for accelerated computation
- Model testing, inference, and performance evaluation

### 🚀 Practical Applications
- Implementing ANN and CNN architectures
- Training deep learning models
- Image classification and feature learning
- Experimenting with custom architectures
- Building reusable training pipelines
- Preparing models for inference and deployment

**Goal:** Develop practical proficiency in PyTorch and learn to implement, train, evaluate, and use deep learning models through clean and reproducible code.

# 5. CNN — Convolutional Neural Networks

## 📘 About This Repository

This repository explores **Convolutional Neural Networks (CNNs)**, a specialized class of neural networks particularly effective for processing image data and learning spatial patterns. CNNs automatically learn hierarchical features, progressing from simple patterns such as edges and textures to more complex structures and objects.

The focus is on understanding convolution operations, feature extraction, network architecture, and the process of training CNNs for computer vision tasks.

### 🧠 Topics Covered
- Fundamentals of convolutional neural networks
- Image representation and preprocessing
- Convolutional layers and learnable filters
- Stride, padding, kernels, and feature maps
- Activation functions such as ReLU
- Pooling operations and dimensionality reduction
- Flattening and fully connected layers
- Building and training CNN architectures
- Loss functions, optimizers, and backpropagation
- Training and validation strategies
- Overfitting prevention and data augmentation
- Performance evaluation and prediction visualization
- Introduction to transfer learning and pretrained CNNs

### 🚀 Applications
- Image classification
- Object recognition
- Medical image analysis
- Image segmentation
- Quality inspection and defect detection
- Facial and visual pattern recognition

**Goal:** Understand how CNNs learn spatial features from images and develop the practical skills required to build, train, and evaluate deep learning models for computer vision.
